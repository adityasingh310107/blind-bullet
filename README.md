# BLIND BULLET

> Aim in secret. Predict your friends. Everyone appears at once and every shot fires together. The last one standing wins.

A fast-paced multiplayer simultaneous-turn shooter built with HTML5, Canvas/WebGL, and WebRTC.

## Features
- **Simultaneous Action**: Everyone plans and locks in their move in secret.
- **Local & Online Multiplayer**: Play locally or create online lobbies with room codes.
- **Zero Install**: Runs entirely client-side in any modern web browser.

## Getting Started
Open `index.html` (or `blind-bullet-public.html`) directly in any web browser.
